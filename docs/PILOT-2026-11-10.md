# Pilot record — KampusMart on an 8 GB laptop (2026-11-10)

This is a builder-machine pilot, not a blind student pilot. It records real
measurements so later claims are not guesses.

## Device

| Item | Value |
| --- | --- |
| OS | Windows 11 Pro |
| RAM | 7.8 GB |
| Shell | PowerShell 5.1 |
| Runtime | PHP 8.2.4 (XAMPP, ZTS x64) |
| Runtime model | PHP built-in server on `127.0.0.1:8081` |
| Database | SQLite file in `run/lab.sqlite` |

## Build and start

| Metric | Vulnerable | Patched |
| --- | ---: | ---: |
| Build files | 15 | 15 |
| Build size (excluding `run/`) | ~0.1 MB | ~0.1 MB |
| Start to healthy | < 3 s | < 3 s |
| Health endpoint | 200 | 200 |

## Runtime footprint

| Metric | Value |
| --- | ---: |
| PHP process working set (idle) | 22.0 MB |
| PHP process private bytes | 9.6 MB |
| Database after seed | < 100 KB |
| Evidence log after 29-check run | ~5 KB |

Design budget was 768 MB for the app and 1 GB peak per laptop. The measured
process is far below that. Browser memory is outside this measurement.

## Listen address and isolation

`Get-NetTCPConnection -LocalPort 8081 -State Listen` reported:

```
LocalAddress  LocalPort  OwningProcess
127.0.0.1     8081       9480
```

Only loopback is bound. A second LAN device cannot reach the target without an
explicit tunnel, which is out of scope for the local package.

## Functional and security checks

- Vulnerable build: 29/29 checks pass, including the three bounded proofs.
- Patched build: 29/29 checks pass; the three proofs are rejected and normal
  commerce, coupon use, and staff flow still succeed.
- Reset: mutated state (3 orders, 2 redemptions, `HEMAT10` uses = 2, 14 evidence
  rows) returned to the seeded state (2 orders, 0 redemptions, uses = 0, 0
  evidence rows) with identical invoice markers.
- Standalone package: unpacked outside the repo, started on port 8085, 29/29.

## Limits of this pilot

- One builder, one device; not a blind student pilot.
- Browser RAM was not measured.
- Only KampusMart exists so far; PerpusDigital and EventPass are not built.
- Difficulty and time-to-proof must still be calibrated with students.
